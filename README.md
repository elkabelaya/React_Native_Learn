# 📱 React Native Mobile Development — курс от Junior до Middle

**Практический курс по разработке мобильных приложений на React Native**  
Курс построен по принципу **Project-Based Learning**: вы будете последовательно разрабатывать реальное приложение **RideGo** — сервис заказа поездок (аналог Uber/Max) с картой, трекингом в реальном времени, push-уведомлениями, онлайн-оплатой и всем, что делает мобильное приложение «мобильным».

---

## 🎯 О курсе

Курс превращает вас из разработчика с базовыми знаниями JavaScript в уверенного **Middle React Native Developer**.

**Ключевые принципы:**

- **Реальное приложение, а не учебные игрушки.** Каждый модуль добавляет полноценную фичу в RideGo: сначала карта, потом трекинг, потом платежи. К концу курса у вас production-ready приложение с релизом в TestFlight и Play.
- **TypeScript (strict) с первого модуля.** Никакого «джейс-по-быстрому». Мидл пишет строгий типизированный код.
- **Две платформы.** Каждый сценарий проверяется на iOS и Android. Вы перестанете удивляться, когда «на iOS работает, а на Android — нет».
- **Проект пишется самими руками** (кроме стартового шаблона). Шаблон можно скопировать один раз, дальше — только ваш код.

**Длительность:** 14 модулей, ~18–19 недель (при 15–20 часах в неделю). Можно растянуть до 6–7 месяцев.

**Целевой уровень:** Middle Mobile Developer (React Native)

## 🚀 Что такое React Native?

**React Native** — фреймворк Meta для разработки нативных мобильных приложений на JavaScript/TypeScript. Один код — два приложения (iOS + Android), рендеринг в настоящие нативные контролы, доступ к всем платформенным возможностям (камера, геолокация, push, платёжные кошельки).

**Почему React Native:**
- 📊 Один из самых востребованных фреймворков мобильной разработки
- 🔄 Нативные UX-паттерны (не «веб, завёрнутый в WebView»)
- 📦 Огромная экосистема: Expo, Reanimated, Maps, Stripe, Sentry
- ⚡ Modern: Hermes, New Architecture (JSI/Fabric) — приложение запускается быстрее и работает плавнее
- 🏢 Стандарт де-факто: от стартапов до крупных компаний (Netflix, Discord, Alibaba, Walmart)

## 🚗 Наш проект: RideGo

**RideGo** — сервис заказа поездок: пользователь видит карту, указывает точку посадки и пункт назначения, выбирает класс авто, вызывает водителя, отслеживает поездку в реальном времени, оплачивает картой и ставит оценку.

**Ключевые возможности к концу курса:**

1. 🗺️ Карта с геолокацией, выбором точки (поиск + перетаскивание пина), маршрутом
2. 🚕 Классы авто (Эконом/Комфорт/Бизнес) с расчётом цены по дистанции
3. 🔎 Поиск водителей: пагинация, поиск с debounce, фильтры, рейтинг
4. 📡 Трекинг в реальном времени: WebSocket, плавный маркер, живой ETA
5. 🔔 Push и in-app уведомления о статусах (включая фон), deep link из push
6. 💳 Оплата: Stripe Payment Sheet, 3DS, decline, idempotency, чек
7. ⭐ Оценка водителя после поездки
8. 📜 История поездок (SectionList, pull-to-refresh)
9. 🤍 Избранные водители, сохранённые адреса, черновик поездки (персистентность)
10. 👤 Профиль: биометрия, способы оплаты, тёмная тема, i18n (RU/EN)

## 🛠️ Технологический стек

| Область | Технология | Зачем |
|---------|-----------|-------|
| Фреймворк | **React Native 0.74+** (New Architecture) | UI, JSI, Fabric, Hermes |
| Платформа | **Expo SDK** (dev builds, config plugins) | Скорость разработки, EAS |
| Язык | **TypeScript (strict)** | Безопасность типов |
| Навигация | **React Navigation** (native-stack, bottom-tabs) | Stack/tabs, deep links |
| Server-state | **TanStack Query** | Кэш, пагинация, мутации |
| Client-state | **Redux Toolkit + MMKV** | Глобальный стейт + персистентность |
| Карты/гео | **react-native-maps + expo-location** | Карта, геолокация, геокодинг |
| Реалтайм | **Socket.IO client** | Трекинг водителя |
| Push | **expo-notifications** | APNs + FCM |
| Формы | **react-hook-form + zod** | Валидация, UX |
| Хранение | **react-native-keychain** | Токены в Keychain/Keystore |
| Анимации | **React Native Reanimated** | 60 fps анимации (worklets) |
| Платежи | **Stripe** (Payment Sheet, test mode) | Карта, 3DS, decline |
| Тесты | **Jest + RNTL + msw + Maestro** | Unit, component, E2E |
| Релизы | **EAS Build / Update + GitHub Actions** | Сторы, OTA, CI/CD |
| Мониторинг | **Sentry + PostHog** | Краши, аналитика, A/B |

**Бэкенд (упрощённый, в параллель):** Node.js + Express + SQLite + Socket.IO — вы пишете мок-API сами (REST + WebSocket + генератор GPS-потока «водителей»).

## ❓ Частые вопросы

**Expo или React Native CLI?**  
Курс — на Expo (dev builds, config plugins, EAS). Это осознанный выбор: в 2024+ Expo покрывает 95% сценариев, включая нативные модули. В модуле 1 вы научитесь аргументировать этот выбор — и понимать, когда Expo Go не хватает.

**Нужно ли уметь Swift/Kotlin?**  
No. Но в модуле 11 вы *прочитаете* нативный код готовых модулей и напишете собственный TurboModule на Kotlin/Swift (это advanced-часть — можно пропустить, если идёте без нативного бэкграунда).

**А если я уже знаю React?**  
Отлично: модули 1–2 пролетите быстрее. Но мобильная специфика (нити, фон, permissions, сторы) — не «React на телефоне». Не пропускайте модули 7–9.

**Windows/Linux?**  
Android-часть курса полностью доступна. iOS-сценарии (TestFlight, biometrics iOS, background modes) — изучаете по теории, на практике — только Android. Для позиции Middle это минус: ищите Mac на неделю практики (в модулях 8–9 обязательно нужен настоящий iPhone).

**Сколько времени на модуль?**  
Ориентир: 15–20 часов в неделю × длительность модуля из графика выше. Полная проходка курса — ~300 часов практики.
